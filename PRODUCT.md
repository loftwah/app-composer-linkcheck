# Product

Reviewed 13 October 2026. Independent open-source App Composer mini-app, owned by #50 in the Composer repository. A site owner inspects reviewed public sites, checks their metadata/icons/share images, exports a dated versioned report, and can import that report into Composer for agent review. The report grants no credentials or deployment authority.

Public access is limited by a route-wide per-location rate limit; this is not a signup service or arbitrary URL proxy. No model calls, database, private identity data or server report persistence. Workers/TypeScript/Effect own bounded IO; native browser controls own presentation. Platform-native unfurls, search indexing, installability and full icon-variant selection remain separate acceptance gates.
