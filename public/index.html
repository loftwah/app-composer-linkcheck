Supported sites and inspection limits

This deployment checks Composer, Guestbook, Showcase, Hello World, Portable AI State and Link Check. A fork can configure its own reviewed public hosts. It reads public HTML and bounded image files without executing scripts.

A link is more than its URL.

See the page title, favicon and share image together. Find missing or conflicting metadata before you send the link.

  • Site icons and browser theme colour
  • Open Graph, X and compact previews
  • Canonical, indexing directives and JSON-LD

The preview uses the fetched tags. Search indexing and platform acceptance need separate checks.
