    What each platform still needs
    Guidance review: 13 October 2026. These source checks are separate from this page’s inspection date. No platform-native sharing action has been performed.
    Open Graph
    Title, type, image and URL are required. Give the image a description. Multiple images are allowed; the first takes preference. Protocol — reviewed.
    LinkedIn
    Its help page describes a 1.91:1 frame, 1200 × 627. Old images can remain cached; use Post Inspector to refresh and check the actual result. Guidance — reviewed. Open Post Inspector.
    X / Twitter
    Inspect twitter:card, twitter:image and their alternative text separately. The former official large-card documentation redirected to the general API overview during this review. Current size/eligibility rules are unverified; this preview does not claim X acceptance. Current documentation destination.
    Facebook
    Use its Sharing Debugger for actual crawler access and cached image checks. The official best-practices page returned HTTP 429 during review; current platform-specific limits are unverified. Open Sharing Debugger.
    Slack
    Classic unfurls use page metadata. Workspace settings and app-provided unfurls can change what appears. Official guide — reviewed.
    Discord, WhatsApp & iMessage
    The compact preview is a layout check only. Platform-specific crawler, cache and crop behavior remains unverified. Confirm by sharing a public test link in each relevant client; no automatic post is sent.
    Search
    A title, description and canonical help describe the page. Google can choose different title text and snippets. Indexing, robots.txt, structured-data eligibility and rankings are separate checks. Google title guidance — reviewed.
    Keep the evidence.
    Your report records the response, image dimensions, source version and inspection time. It grants no account or deployment access. The checker makes no model calls and does not execute page scripts or save reports on a server.
